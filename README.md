# AI Website Copy Generator for a Local Fashion Store

## Future Interns — Prompt Engineering Task 1

### Project Overview

This project demonstrates a structured AI prompt workflow for generating website-ready copy for a local clothing and fashion store in Ahmedabad, Gujarat.

The goal is to create clear, simple, persuasive, and conversion-focused website content using prompt engineering.

## Business Context

- **Business Type:** Local Clothing & Fashion Store
- **Location:** Ahmedabad, Gujarat, India
- **Target Customers:** Young adults and fashion-conscious customers
- **Product Categories:** Men's clothing, Women's clothing, Casual Wear, Ethnic Wear, Fashion Accessories
- **Primary Goals:** Increase store visits, customer enquiries, collection discovery, and online orders

## Task Objective

The prompt system was designed to generate:

- Homepage copy with a clear value proposition
- Product and collection descriptions
- Strong calls-to-action (CTAs)
- Audience-specific messaging
- Different brand-tone variations
- Website-ready content

## Prompt Engineering Approach

The prompt follows a structured workflow:

1. Define the AI's role as a professional website copywriter.
2. Provide the business type, location, audience, products, and business goals.
3. Define the required website-copy sections.
4. Focus the messaging on customer needs and benefits.
5. Generate conversion-focused CTAs.
6. Adapt the messaging for different customer groups.
7. Generate different brand-tone variations.
8. Apply rules to avoid unsupported business claims.
9. Specify a consistent output structure for the final content.
